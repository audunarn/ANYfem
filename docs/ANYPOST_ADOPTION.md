# Default result processing

ANYfem 0.4.2 requires ANYpost 0.1.2, ANYsolver-results 2.1.1, ANYmesher 0.5.1 and, for the desktop viewers, ANY3dView 0.5.6. The normal result workflow uses ANYpost; the archive demonstration remains an additional entry point.

`post.access.ShapeProvider` extracts actual source displacement and recovered components through existing owner APIs. `LiveResultAccess` retains one query session per result revision, with an aggregate 2 GiB LRU budget. Public `evaluate_field` still observes mutable legacy shapes on each independent call. Generic native-sample reductions and envelopes run in ANYpost. Shell membrane/bending surface pairs use `anysolver_results.shell_surface_component`; ANYfem does not introduce stress equations.

The 128 MiB working limit covers query snapshots, extraction, reductions and display conversions. Source mechanical recovery has a separate memory cost: its retained arrays and containers are charged to the application cache after recovery; its execution workspace and the model itself remain source/RSS costs. This limit is not a bound on the whole solver process.

The desktop workflow uses one serial worker with independent latest display, inspection and history channels, and an ordered export channel. Unrelated reads do not supersede a display or export. Each result is settled on the GUI owner before the next heavy cache query starts; the owner does not wait for recovery or I/O. Model, result, project and frame replacements supersede outstanding requests. Closing retires the worker, settles cancelled queued callbacks and releases their payloads, then closes readers. Source replacement cancels all channels; frame/control changes cancel display work while preserving ordered exports. Captures and cached playback receive explicit cancellation cleanup. Legacy `anyfem.result` sidecars delegate fields, histories and tables to ANYpost, retaining their own frames, IDs, units and provenance. File verification and metadata preparation run on the worker.

The desktop keeps only the selected stored reader active. Switching to stored access retires live query caches; switching to live access releases inactive stored-reader caches without retiring their datasets. Genuine dataset retirement is terminal. Stored readers reserve 128 MiB of the aggregate budget for old/new published fields and scalar buffers. Mode switches clear the opposite geometry key, so a different source or deformation cannot reuse an unrelated scene. Independent programmatic readers remain caller-owned.

Warm GPU component changes reuse CPU entity maps, mesh handles, positions, connectivity and semantic picking. Only scalar and appearance state changes. Geometry, deformation, overlays or style changes rebuild the scene; software viewers retain their existing redraw behavior. Nodal coloring preserves the historical element-mean display reduction, identified in the legend. Source node values remain unchanged for queries and exports. No implicit stress averaging or new recovery is introduced.

An incomplete analysis may expose an explicit stored source snapshot. Its analysis status is preserved and it carries no accepted-state or portable-certification claim. Ordinary completed-case reads and envelopes keep their admission rules. Unsupported quantities and missing frames refuse explicitly.

Returned linear results and successfully imported stored datasets are completed data cases, without solver certification. Imported analysis status remains unknown. Generic status-less objects are unknown cases; finite vectors alone do not establish completion. Envelopes retain the total submitted `shape_count` and expose admitted and failed case identities/counts separately. Failed cases do not contribute numerical values.

Programmatic `ResultField.read(frame=...)` and `values(frame=...)` keep local field-row indexing. Desktop requests resolve the root frame through the field's declared frame mapping and refuse missing frames instead of clamping to another row. An all-frame programmatic read is admitted as one aggregate transport operation; callers can select individual rows when it exceeds the working limit.

The worker waits cancellably for query exclusivity; owner publication uses a short nonblocking reservation. An overlapping publication is refused rather than making the GUI wait through recovery or file reads. Publication refusals discard pending reservations and leave the request queue scheduled for the next valid request. Session-created recovery is retired during envelope case changes and eviction; user-provided source recovery is preserved. Envelope callback admission includes both nested extraction and Field conversion, leaving the outer engine's scratch allocation within the same working limit.

Probes, histories, line samples, reports and CSV queries share the default query route. Inspector previews load on the worker. PNG, GIF and cached playback wait for owner publication before capturing a requested frame. Interactive Qt controls stop cached animation before applying a new field or appearance. Qt frame evidence uses the native surface signal; it does not claim the Tk listener's timestamp interface for Qt.

Package publication and full-scale scientific/performance acceptance are separate from these application changes. See the evidence handoff for the actual checks, source identities and remaining limitations.

GPU NaNs use the viewer's existing invalid-scalar colour; software replay retains the legacy missing-value colours. This affects presentation only: absent values and engineering NaNs are never replaced with zero. Worker-prepared scalar and colour buffers keep the CPU replay current without rebuilding geometry on warm changes. The geometry identity hashes exact array bytes, including overlays, rather than abbreviated NumPy representations. Root-frame CSV and table display resolve quantity-local rows explicitly; imported nodal stresses remain node-valued in envelopes. Envelope statuses report admitted/failed coverage separately from the currently selected shape.


GUI shutdown settles capture callbacks immediately and schedules result readers for retirement on the same serial worker after its active query finishes. It never waits on noninterruptible mechanical recovery and does not start a second numerical worker. Project locks/listeners may close while immutable query inputs remain retained by that retiring worker. A later result request waits asynchronously for retirement and uses a fresh coordinator.

Client CSV/report writes use a same-directory temporary file, cancellation checks and atomic replacement. A completed write has an explicit committed outcome and is reported with captured source context even if source invalidation precedes owner delivery. Precommit cancellation preserves the previous destination. Late shutdown writes are recorded/logged without touching destroyed widgets. Routine read supersession does not replace unrelated status messages; result warnings clear only when they still own the visible status.

Both frontends share workbench descriptor semantics. Job changes cancel display/inspection/history and preserve explicitly captured ordered exports. Cold and warm display reservations measure the same actual scalar/CPU-colour buffers. Transient preparation uses geometry digest and primitive indices rather than retaining handles or patches, is stripped after publication, and CPU replay replaces patches rather than mutating cached scenes. Explicit persisted colour limits control worker and owner colours alike.

Raw stored scalar values preserve their sign. The legacy default display norm of a singleton component is retained and labelled absolute scalar; explicit component selection remains the signed source display where its original sample reduction permits. Identical complete axes containing paired NaNs may map by row; independently ambiguous axes remain unavailable. Cached artifact identity/provenance decoding and missing-key ArtifactError are the same as cold access.

Retirement cleanup attempts all resources despite individual failures and records bounded diagnostics. Repeated close submits cleanup on the same retired serial executor; reactivation shuts that idle executor before starting a new coordinator. Software persisted contours take the software scene path on every component. Failed conversion is admitted before GPU publication. Cancelled ordered exports report their outcome without replacing newer unrelated status. One-dimensional singleton scalars retain their sign and scalar label; the historical multi-axis singleton norm remains explicitly absolute.
Ordered exports still inside an atomic commit report retirement as pending, then report the actual committed or precommit-cancelled result on the owner while the GUI is alive. Shutdown logs/retains actual commits without calling destroyed widgets. Status revisions distinguish identical text from a newer publication, so warning clearing and cancellation do not overwrite it.
Retired export reports take a completion snapshot before draining, so a concurrently finished write cannot lose its final report. Actual write errors remain failures after source invalidation or retirement; only explicit cancellation/not-started work is reported cancelled. Settled delivery records release payload/callback references even if a dispatch arrives after close.
Late committed exports preserve a newer solve status and show their captured source/file success notice in the existing log or report. Recent committed outcomes are bounded to ten with an exact cumulative commit count; every written file remains intact. Export diagnostics logged behind a newer status use their own bounded list and do not trim unrelated shared diagnostics.
Exports deferred while resources retire keep the original status ownership through every retry. Shutdown completion logging covers both already committed and pending commits exactly once, preserving the captured source and actual written path.
A deferred ordered export cancelled by source owner replacement reports precommit cancellation through its original status ownership while the GUI remains alive. The stale source is never loaded, cleanup runs once, and closing suppresses widget publication.
Deferred queries carry a source-only generation through retirement waits. Model/loading revision changes and explicit source retirement cancel stale deferred exports even when owner references remain the same. Display/read invalidations preserve captured ordered exports; cancellation still respects original status ownership and closing suppression.
