## Updated decisions and acceptance

1. **Trustworthy lifecycle evidence** (before Darwin acceptance): replace Linux
   `/proc` assumptions in test liveness checks, add a positive live-process control,
   explicitly require named Darwin tests to pass in JUnit, and deliberately replace
   Darwin-refusal expectations. A partially skipped run cannot establish support.
2. **Darwin contained workers**: retain spawn, pre-dispatch registration and ready/go
   handshake; use an owned session/group, fresh-interpreter guardian with explicit
   FD inheritance and an independent worker-side parent/guardian watch. No raw fork
   or Linux prctl on Darwin. Inspect processes with psutil + POSIX getpgid/getsid
   (no duplicate private libproc/sysctl ABI). Fail closed on ambiguous ownership,
   inspection failure, surviving children or deadlines; publish only after verified
   retirement of the entire owned session, including the pool's separate groups.
   Never signal a reaped worker's reusable numeric group. Positive controls,
   parent/worker/guardian death and zombie-leader
   coverage precede claims. Preserve concurrent terminate_on_cancel/worker_priority.
3. **Recovery**: add Darwin start identity without changing lock schema. Preserve
   hostname-mismatch/read-only policy; test hostname drift and old missing tokens.
   Exercise Unicode/path round-trips without changing project identity semantics.
4. **Installation and CI**: align the GUI geometry dependency with the existing
   versioned public contract, include WebGPU in the default GUI (source confirms
   auto selects WebGPU), and update licensing. Build a pinned ecosystem wheelhouse
   then resolve/install wheels in a clean venv outside source. Require native
   ANYmesher; keep ANYgeometry's production-default backend, with no new native
   geometry gate. Verify actual runtime/backend and preserve compiler settings.
5. **Acceptance**: Mac lanes run installed-artifact checks, required Darwin lifecycle
   tests, existing Qt/software integration and numerical/reference contracts.
   Record BLAS/compiler/native identities. Investigate numerical discrepancies
   within owner contracts; never loosen existing exactness/tolerances. Optional
   Metal probe/rendering is separate and unavailable means not_verified. Windows
   regressions run locally; Linux and macOS gates remain pending until executed.

Dependencies: 1 enables 2; 2/3 and 4 enable integrated Mac acceptance. Main risks:
Darwin process semantics, inherited sentinel descriptors, runner startup margins,
artifact/version pin drift, ARM compiler/BLAS differences and unavailable Metal.
