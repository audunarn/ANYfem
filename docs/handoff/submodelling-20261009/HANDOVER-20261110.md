## Open findings (2026-11-13)

1. **The run-time offset-side check skips plate-interior stiffeners.** `_require_scalar_offset_sides`
   in `submodel_jobs.py` finds a beam's plates through the faces that use its edge. A stiffener
   rebuilt by `submodel_attached_cut.py` lies on no face edge, so the check finds no plate and
   skips it.
   - Reproduced on origin/main `069c789`: an archived parent mesh with that stiffener's offset
     mirrored is not refused, in either the source-mesh or the child-mesh check.
   - Draft fix, uncommitted and with no test: worktree `C:/ANYworkspaceWork/sm8`, branch
     `claude/submodel-attached-offset-side`. It adds the attachment targets of the beam's members
     (face, edge or sheet), as the mesher does. With it, the source-mesh check refuses the
     mirrored case and accepts the correct mesh.
   - Before merging, a child-mode test is needed. In a stand-in check (the full parent mesh used
     as the child) it refused a correct mesh where the stiffener end meets another plate. A
     real child carries these stiffeners inside one flat face only.
   - The owner has parked the fix; no ANYfem test is to be added for now.
2. **Child edits do not recheck beams.** `validate_child_edit` does not rerun the section, frame,
   offset or attachment checks (`CUT_BEAM_FRAME`, `CUT_BEAM_OFFSET`), and beam lineage is not
   kept with the child. Whether carried beams may be edited is the owner's decision.
3. **Untested:** `CUT_BEAM_OFFSET` refusals for attached members; beams near the box of a solid
   cut (the code refuses them, but no test covers it).
4. **ANYfem meshing.** The default mesher rejects a single L-shaped plate at 0.2, 0.1, 0.05 and
   0.04 (structured quality or S3 admission).

## Tests

ANYfem, from the repository root. The runner puts `C:/Github/<repo>/src` on the path for
ANYfeSolver, ANYmesh, ANYgeometry, ANYmaterial, ANYfileIO and ANYloads. `S4A_<REPO>` overrides one
of them (for example `S4A_ANYGEOMETRY`), and `S4A_ROOT` overrides the parent folder. Without a
test path among the arguments it runs every `tests/test_submodel*.py`. Use a Python with pytest (Python 3.14 here)
and clean sibling checkouts:

```
python docs/handoff/submodelling-20261009/s4a/run_tests.py -p no:cacheprovider --basetemp=<writable dir>
```

Pytest needs a writable `--basetemp`; the default temp folder is access-denied on this machine.

ANYgeometry has `tests/test_volume_cut.py`:

```
PYTHONPATH=src python -m pytest -q tests/test_volume_cut.py -p no:cacheprovider
```

The A5 error budget is optional and takes about 3 minutes:

```
python docs/handoff/submodelling-20261009/s4a/run_tests.py docs/handoff/submodelling-20261009/s4b/test_a5_budget.py -s --basetemp=<writable dir>
```
